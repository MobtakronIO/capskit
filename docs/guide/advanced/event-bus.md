# Event Bus (Pub/Sub)

The built-in event bus allows capsules to communicate asynchronously.

> **Note**: The event bus works identically in both the **Cap model** (`caps.ts` + `.cap/` directories) and the legacy `manifest.ts` format. In the Cap model, event subscriptions are declared in each Cap's `cap.meta.ts`. See the detailed [Events](../events.md) guide and [Capsules](../capsules.md) for full documentation.
