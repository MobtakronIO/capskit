# Kernel Interceptors

Interceptors are global middlewares that wrap every action call in the system.

> **Note**: Interceptors are kernel-level middleware and work identically regardless of whether you use the **Cap model** (`caps.ts` + `.cap/` directories) or the legacy `manifest.ts` format. See the detailed [Interceptors](../interceptors.md) guide and [Capsules](../capsules.md) for Cap model documentation.
